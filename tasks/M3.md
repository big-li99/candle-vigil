# M3 — 声音与收尾打磨（最后一轮功能开发）

基线 `main` 已是一局完整游戏（10 波、BOSS、升级、失败/通关）。这一轮只做"让人愿意玩下去"的部分：
**音符、可读性、手感微调**。不加新玩法、不加新内容。

## 1. 声音（`src/audio.js`，全部 WebAudio 合成，不许放音频文件）

- 一个 `AudioContext`，第一次按键时 `resume()`（浏览器策略），所有声音走一个 master gain（默认 0.35）。
- 下面每个事件一个合成音色（方波/三角波 + 噪声 + 包络，单个 ≤ 0.35s，可以用 detune 做"音高递增"）：
  | 事件 | 音色方向 |
  |---|---|
  | 剑斩起手 / 命中 | 短促高频"唰" + 命中时更低的一声"啪" |
  | 锤击 | 低频"轰" + 噪声尾巴 |
  | 冰霜新星 | 上行的清脆和弦（三个音依次） |
  | 闪电 | 噪声爆裂 + 低频 Thunder |
  | 毒云 | 低沉的"咕"（只响一次，不循环） |
  | 治疗 | 两音上行，柔和正弦 |
  | 击杀 | 短促"叮"，音高按连击数递增（每杀 +2 半音，上限 +12） |
  | 格挡 | 金属"当" + 高频泛音 |
  | 被咬 | 低频闷响，不刺耳 |
  | 波次开始 | 两音号角；BOSS 波更低更慢 |
  | BOSS 吐息前摇 | 上行的火声（噪声滤波扫频），1.5s 内完成 |
  | 失败 / 通关 | 下行三音 / 上行四音 |
- 倍速/静音：`M` 切换静音（存 `localStorage`），`+` `-` 无（不做音量键）。
- **不要**在 `draw()` 里创建节点；所有节点在事件发生时创建、播完自动断开。

## 2. 读得清（可读性）

- 烛火 < 30 时：烛火条闪红（4Hz）、烛火火苗亮度略微加大、HUD 烛火数字变红 —— 一眼知道"快死了"。
- 连击 ≥ 3 时在玩家上方显示 `xN` 小字（用 `painter.text`，不要用 `ui/combo-counter` 那张写死 x5 的图），≥ 10 时改金色。
- 伤害数字最多同时 4 个，超出只冒火花（M2a 已有 `numbersCapped`，确认它在跑）。
- 暂停时画面压暗（半透明黑 + 现有 PAUSED 字样），不要停掉动画。

## 3. 手感微调（只调参数，不加系统）

- 命中定格：普通 0.05–0.08s，锤击/闪电/BOSS 死亡最多 0.14s；超过就该感觉"卡"了。
- 震屏：普通 1px、锤击 2px、BOSS 死亡 3px，时长 ≤ 0.2s，结束后 canvas transform 必须回到空字符串。
- 施法被打断时：角色抖动 + 一声"闷响" + 烛火条闪一下（已有，接上音效即可）。
- 法力见底（< 10）时法力条闪一下并变暗红。

## 4. 性能与稳妥

- 同屏 8 敌 + BOSS + 2 个 act：60fps（这是硬指标）。
- 所有音效都要能在 `AudioContext` 被浏览器挂起时静默失败，不许抛错（headless 测试环境听不到声，也不能报错）。
- `?autotest=1` 的断言里加一条：静音开关能切换且写入 localStorage。

## 5. M2c 验收没过的一条

结局页的**背景变亮没实现**：`NIGHT ENDS` 的统计面板正常，但天空还是原来那片夜空。补上——结局开始时把 backdrop 换成更亮的一档（或叠一层冷蓝 → 暖白的渐变 + 一点点上升的光），要肉眼可辨"天亮了"。
