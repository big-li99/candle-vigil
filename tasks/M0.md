# M0 — 骨架（可运行的空壳战场）

Read `DESIGN.md` §2–§3 and `CLAUDE.md` first. This milestone builds the renderer + input + scene skeleton only.
**No gameplay, no enemies, no spells yet** — M1 does that.

## What already exists

- `vendor/pixelfx/` — vendored copy of pixelfx (`src/core/*`, `src/fx/*`), read-only. Import with relative paths, e.g.
  `import { createFrame, composite, hex } from "../vendor/pixelfx/src/core/index.js"`, effects like
  `import * as swordSlash from "../vendor/pixelfx/src/fx/melee/sword-slash.js"`.
- `docs/spike/spike.js` + `docs/spike/spike.html` — a **working** 384×216 single-frame prototype (60 fps, 20 effects).
  It is the reference for the renderer; lift and clean `src/frame.js` out of it rather than starting from nothing.
- `package.json` with `esbuild` installed and `dev` / `build` scripts already wired.
- `docs/CATALOG.md` — every effect id with size and duration.

## Build this

1. **`index.html`** — one `<canvas id="game">`, dark page, centred, `image-rendering: pixelated`, loads `dist/game.js`.
   No frameworks, no CDN, no web fonts.
2. **`src/frame.js`** — the world buffer: `createFrame(384, 216)`, `backdropArray` built once from
   `backdrop("sky", 384, 216, GROUND=196)`, a `render(drawWorld)` that clears, calls the scene, composites once,
   `putImageData`, and handles the integer CSS scale + resize + screen shake offset (shake offsets the canvas via CSS
   transform, not the buffer). Export `GROUND`, `W`, `H`.
3. **`src/main.js`** — fixed-step loop: accumulator at 1/60, max 4 catch-up steps, `requestAnimationFrame` render,
   `P` pause, window blur auto-pause. Report fps into `__game.stats`.
4. **`src/input.js`** — keyboard state (`down` set + `pressed` edge set cleared each step), plus a `bind` map for
   `1–4`, `Space`, `Esc`, `P`. Touch: tapping the canvas left third = `1`, right third = `2` (placeholder for M1).
5. **`src/assets.js`** — an id → module registry for the 24 effects listed in `DESIGN.md` §4 (import them explicitly;
   a plain object keyed by `"melee/sword-slash"`). Export `get(id)`.
6. **`src/game.js`** — scene state machine with two states for now: `title` and `field`. Title shows the game name and
   "PRESS ANY KEY"; `field` is an empty snow-night stage: sky backdrop, `weather/snow.js` drifting loop, the candle
   (`fire/candle`) at `x=24, y=196`, two `fire/torch` on the back wall, and a standing player placeholder drawn with
   `drawActor` + `stockActor` at `x=56, y=196` (no movement).
7. **`src/ui/hud.js`** — a HUD pass with a fresh painter: `WAVE 1/10`, candle bar, `MANA`, four empty skill slots with
   numbers 1–4, dark plates behind each. Use `p.measure()` for layout, `hex()` for every colour.
8. **`src/debug.js`** — `window.__game` per `CLAUDE.md` (snapshot/spawn stub/cast stub/setWave/skipUpgrade/god/pause/
   stats), `window.__report` after 2.5 s, `?fx=<id>` playground mode (loops one effect at screen centre with its name,
   duration, size printed in the HUD), `?autotest=1` skeleton that currently just asserts "no console errors, fps>55,
   canvas 384×216" and sets `<body data-autotest>`.
